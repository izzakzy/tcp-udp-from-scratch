# tcp-udp-from-scratch

Small TCP and UDP client/server programs in Python, written for learning
network programming and security basics.

## Usage

### TCP
```bash
# Terminal 1
python tcp/tcp_server.py
# Terminal 2
python tcp/tcp_client.py
```

### UDP
```bash
# Terminal 1
python udp/udp_server.py
# Terminal 2
python udp/udp_client.py
```

Type a message in the client and the server replies with an ACK.
Type `quit` to exit the client.
